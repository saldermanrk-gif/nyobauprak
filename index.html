Tutorial Praktik TKJ: Setting IP Static di Windows

Panduan dasar konfigurasi alamat IP jaringan komputer untuk siswa TKJ.

Apa itu IP Static?

IP Static adalah alamat IP yang diatur secara manual pada komputer agar alamatnya tetap (tidak berubah-ubah) di dalam jaringan lokal (LAN).

Alat dan Bahan

  • 1 Unit PC / Laptop (Windows 10 / 11)
  • Kabel LAN (Straight) atau koneksi Wi-Fi

Langkah-Langkah Konfigurasi

  1. Tekan tombol Windows + R pada keyboard.
  2. Ketik ncpa.cpl lalu tekan Enter untuk membuka Network Connections.
  3. Klik kanan pada adapter jaringan (Ethernet atau Wi-Fi), lalu pilih Properties.
  4. Cari dan klik 2x pada Internet Protocol Version 4 (TCP/IPv4).
  5. Pilih opsi Use the following IP address, lalu masukkan konfigurasi berikut:
IP Address          : 192.168.10.2
Subnet Mask         : 255.255.255.0
Default Gateway     : 192.168.10.1
Preferred DNS Server: 8.8.8.8

6. Klik OK pada semua jendela untuk menyimpan pengaturan.

Cara Pengujian

  1. Buka Command Prompt (CMD).
  2. Ketik perintah ipconfig untuk memastikan IP sudah berubah.
  3. Ketik ping 192.168.10.1. Jika muncul balasan Reply from..., artinya konfigurasi berhasil.
